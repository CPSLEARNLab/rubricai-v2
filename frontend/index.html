FAQ
Common questions.
What file formats does RubricAI accept?+
RubricAI accepts CSV and Excel (.xlsx, .xls) files for participant data, and Markdown (.md) or plain text files for rubrics. Column names are auto-detected — you can override them in the column mapping modal if needed.
How does it handle different CSV column names?+
The system uses smart pattern matching to auto-detect columns like participant IDs, transcript fields, completion status, and batch groups. You can always review and correct the mapping before running an evaluation.
Can I choose which indicators to evaluate?+
Yes — all indicators are selected by default. You can deselect any indicator in the Rubric Framework tab. You can also assign each indicator to a specific session using the checkbox-based session mapping table.
How are scores calculated?+
Claude AI evaluates each transcript against the rubric criteria and assigns a score of 1–4 (Beginning, Developing, Applying, Mastery) per indicator. Communication and Critical Thinking aggregate scores are computed server-side from the individual indicator scores — the AI does not average them.
Can I filter results by class or batch?+
Yes — if your CSV has a batch or group column, batch filter chips appear automatically on the Class Overview and Summary & Charts pages. Clicking a chip filters all KPIs, charts, and the participant table to that class only.
Is my data stored anywhere?+
No data is stored persistently. All evaluation runs in memory for the duration of your session. The rubric file is temporarily saved on the backend server only to process your run. No participant data is retained after the session ends.

How to Use RubricAI
Everything you need to know to run your first evaluation.
⚡ Quick Start — 4 Steps
Follow these steps in order for a complete evaluation run.
1
Data Setup (optional but recommended)
Go to Data Setup and fill in your course name, cohort, simulation type, and researcher expectations. This context is fed directly to the AI — the more detail you provide, the more accurate and relevant the scores will be.
2
Upload Your Rubric
Go to Rubric Framework and upload your rubric file (.md, .txt). The app will auto-parse all clusters, indicators, and 4-level descriptors. Check that all indicators are detected correctly. Use the manual parser override dropdown if indicators are not showing up.
3
Upload Your CSV & Run
Go to Upload & Evaluate and upload your transcript CSV. Columns are auto-detected — click "Edit Mapping" to verify or fix column assignments. Then click Run Evaluation. Results stream in live as each participant is evaluated.
4
Review Results
Go to Class Overview to see all scores. Click any participant ID to see their full evaluation with rationale, feedback, and transcript quotes. Go to Summary & Charts for cohort-level analytics. Export CSV or PDF reports from the top right.

🎛️ Session–Indicator Mapping
How to control which indicators are evaluated in which session.
What is session mapping?
Each indicator in your rubric can be assigned to one or more sessions. For example, Communication indicators might only apply to the User Interview, while Critical Thinking indicators apply to both sessions.
Default behaviour
By default, ALL indicators are assigned to ALL sessions. This means every indicator will be evaluated in every session that has a transcript.
How to change it
In the Rubric Framework page, scroll down to the Session–Indicator Mapping table. Uncheck any session for an indicator to exclude it from that session's evaluation.
🔧 Troubleshooting
Common issues and how to fix them.
My rubric uploaded but no indicators were found+
The parser couldn't detect your heading levels. Go to Rubric Framework, find the "Parser Level" dropdown next to the upload button, and manually select the heading level used for your indicators (e.g. #### for Level 4 headings). Try each option until your indicators appear.
My CSV uploaded but transcript columns weren't detected+
Click "Edit Mapping" in the Upload & Evaluate page. A modal will show all your CSV columns — manually assign which column contains the transcript for each session. Make sure to save by clicking "Confirm Mapping".
Some participants show N/A scores+
This usually means the transcript was too short (under 50 characters) or empty for that participant. Check your CSV to make sure the transcript columns are correctly mapped and contain full transcript text.
Client conversation transcripts are not being evaluated+
Check the column mapping — the client transcript column may not have been detected. Click "Edit Mapping" and make sure the correct column is assigned to "Session 2 Transcript". Also check that those participants actually have client transcripts in the CSV.
The evaluation is slow or timing out+
Large evaluations with many participants and indicators take time. The app evaluates up to 10 participants in parallel. A 16-participant run with 29 indicators typically takes 3–5 minutes. Make sure your backend is running and your API key has sufficient credits.
Professional Agency or other domains not showing in KPI cards+
Domain KPI cards are generated automatically from your rubric structure. Make sure your rubric uses ## headings for domain names (e.g. ## Professional Agency) and ### for clusters within each domain. Re-upload the rubric after fixing the structure.
How do I set up my API key?+
Create a file called .env in the backend folder with the line: ANTHROPIC_API_KEY=your-key-here. You can get an API key from console.anthropic.com. Make sure you have sufficient credits — a 16-participant run with 29 indicators costs approximately $1.
